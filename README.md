1. Enter https://www.win-rar.com/start.html?&L=0 and install WinRAR
2. Click to download as ZIP
3. Unpack the ZIP that you download by right-clicking and "Extract here" using WinRAR
4. Open IDE that is convenient for you(I used VS) and open as folder project in your IDE
5. After project is opened, You would like to enter CMD as Administrator and enter next commands:
	
	pip install ursina
	pip install perlin-noise
	pip install panda3d

6. And you should be OK running the game!
